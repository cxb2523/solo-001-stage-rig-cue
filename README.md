# 舞台吊杆 Cue 预演台

把"拿本子排吊杆动作"换成可拖拽、可整段预演的台子。纯 Node 20 内置模块，无任何第三方依赖；前端原生 HTML/CSS/JS，不引框架。

## 运行

```bash
node --test          # 全部单元/验收测试
node src/server.js   # 起服务，默认 http://localhost:8080
```

打开页面后自动加载 `data/rig.json`（12 根吊杆台账）和 `data/cues.json`（8 条 Cue）。

- 左侧：舞台剖面，左列吊杆、右列配重架，整段预演时随时间轴运动。
- 中上：Cue 卡片，拖拽或用 ↑/↓ 换序；**换序后所有时间点、过载段、冲突与等待统计整体重算**，不是只挪标签。
- 中下：时间轴，红色块即配重过载段；黄色竖线为播放头。
- 右侧：逐步计算过程（每根杆的梯形速度规划、每段净载荷）和跑完汇总。
- "提交预演"按钮在存在过载段时被禁用并列出被拦截的 Cue。

## 联动策略的取舍（重要）

题目给了两种做法，本台选 **各走各的速度、终点对齐（慢杆照常走，快杆延迟启动）**，不选"按同一速度走"。理由：

1. **不动台账参数**：每根杆的速度、加减速时间是按该杆机构能力和景片安全要求单独编的；强行统一成一个速度，等于偷偷改了数据，操作员照本宣科时拿到的是未授权参数。
2. **慢杆决定节拍，风险可见**：谁慢谁拖后腿直接算成等待时间，最长等待超容差（`syncWaitToleranceSec`，默认 2s）就报"联动速度不同步"，并点名拖后腿杆和每根快杆的等待秒数——这正是排练时要消灭的东西。
3. **物理上更稳**：快杆延后启动、与慢杆同时到位，避免快杆提前到位后长时间吊挂的静载风险，也不需要中间悬停再二次启动。

代价：快杆的启动时刻被推迟，总节拍等于最慢杆。如果导演要求齐起齐落，正确做法是回到台账/Cue 里把快杆速度调下来（或升级慢杆机构），而不是在软件里假装同步。

## 计算模型

- 高度：距栅顶下放米数，`0` 为栅顶（最高），越大越低。
- 每根杆的动作是梯形速度规划：加速段（匀加速）→ 匀速段 → 减速段；行程走不完加减速时峰值速度自动削顶成三角形曲线。
- 配重只平衡电机侧静载，不能替钢丝绳/吊点/卷扬机构卸力，所以"过载"按**吊点侧有效拉力**对该杆额定载荷判定（`a` 向下为正）：
  - 匀速：`T = payload`
  - 加速下放 / 提升刹车（加速度向下）：`T = payload·(1 + |a|/g)`，拉力增大
  - 提升启动 / 下放减速（加速度向上）：`T = payload·(1 − |a|/g)`，拉力减小
  - 任一段 `T > ratedLoad` 即过载，时间轴上该段染红并写明杆号、Cue、时刻与拉力值；过载 Cue 一律禁止提交。
- 联动：快杆 `等待 = 组内最慢时长 − 自身时长`，到终点同时到位。
- 换序：每条 Cue 首尾相接排时间轴；同一根杆在新顺序里的起点与其上一位置（前一条 Cue 终点，或台账家位）不一致报"连续性"冲突（换序立即可见）；越限位报行程冲突。
- 同一份 Cue 表连算两次：引擎是纯函数，全部数值四舍五入到 3 位小数，结果完全一致（有专门测试锁定）。

## 样例数据埋点（验收对照）

- **配重过载两处**（加速下放瞬间吊点拉力超额定）：
  - `Q2` 的 `B02`（一幕杆，额定 200kg，配重 150kg，挂 195kg 景片以 0.6m/s、1s 加减速急降）：加速段拉力 `195×(1+0.6/9.81)=206.9kg > 200kg`，时间轴 `9.5–10.5s` 染红。
  - `Q5` 的 `B08`（景片杆乙，额定 290kg，配重 210kg，挂 285kg 以 0.6m/s、1s 加减速急降 10m）：加速段拉力 `302.4kg > 290kg`，时间轴 `95.2–96.2s` 染红。
  - 两条 Cue 禁止提交预演。
- **联动速度不同步一处**：`Q4` 中 `B03` 以 0.2m/s 走 10m（54s），`B06` 以 0.8m/s 走 4m（7s），`B06` 需等待 **47s**（远超 3s 容差），`B03` 被标记为拖后腿杆——也是全台最长等待。其余联动组（Q3/Q6/Q8）等待均 ≤3s，不报警。

因此原样例顺序下页面应显示：**冲突 3 条（2 过载 + 1 联动不同步）、最长等待 47s（B06 侧灯杆），拖后腿杆为 B03；Q2、Q5 不可提交；总时长 153.8s**。

## 目录

```
data/rig.json       吊杆台账（12 根，含限位/额定载荷/配重/家位）
data/cues.json      Cue 表（8 条，含过载与不同步埋点）
src/engine.js       纯计算引擎（Node 与浏览器共用同一份源码）
src/server.js       零依赖 HTTP 服务 + /api/schedule 重算接口
public/             原生前端（剖面、时间轴、逐步过程、汇总）
test/engine.test.js node:test 验收测试
```
